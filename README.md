# Chinook SQL Data Analysis

This project explores the **Chinook music store database** using SQL to uncover insights about sales, customers, and music trends.  

---

## Business Questions Explored

1. Which artists have released the most albums?  
2. What are the top-selling tracks by revenue?  
3. Who are the best customers by total spend?  
4. Which countries generate the highest average invoice totals?  
5. What are the most popular music genres by sales?

---
