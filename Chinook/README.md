# Chinook SQL Analysis

This project analyses the Chinook music store database.

CSV files correspond to the following queries:

- top_artists_by_albums.csv → Top 10 artists by number of albums
- top_tracks_by_revenue.csv → Top-selling tracks by revenue
- top_customers.csv → Top customers by total spend
- avg_invoice_per_country.csv → Average invoice total per country
- popular_genres.csv → Most popular genres by sales
